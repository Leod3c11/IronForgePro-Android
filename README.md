# 🏋️ IronForge Pro 8.0 — Visual Studio Edition

Aplicativo nativo Android (**Kotlin + Jetpack Compose + Lottie + AGSL RuntimeShader**) com pacote visual completo integrado:
1. **Tipografia Esportiva & Editorial (`Barlow Condensed` + `Inter`):** Títulos numéricos condensados de alto impacto combinados com leitura ultra-nítida.
2. **Animações Lottie Vetoriais (`launch_logo`, `flame`, `target`, `confetti`):** Feedback animado no cadastro, métricas de tonelagem, prontidão muscular e celebração de recordes.
3. **Shader AGSL Orbital (`OrbitingGlowBanner`):** Borda luminosa orbital nativa no Android 13+ (com fallback suave para versões anteriores).
4. **Renders 3D & Miniaturas de Exercícios:** Kettlebell 3D, anilhas olímpicas 3D, ilustrações de objetivos por biotipo, miniaturas fotográficas dos movimentos e ecossistema de wearables (*Google Fit*, *Garmin*, *Fitbit*, *Strava*).
5. **Vídeo Studio Coach (`welcome_pt.mp4`):** Boas-vindas em vídeo nativo integrado à configuração inicial.
